# Agisse

[English](README.md) · **Nederlands** · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Italiano](README.it.md) · [Polski](README.pl.md)

> Deze vertaling is nog niet nagelezen door een moedertaalspreker. Verbeteringen zijn welkom in een pull request.

Agisse is een copiloot voor je zoektocht naar werk, voor studenten en starters in Europa. De naam is Frans, uit « il faut que j'agisse »: "ik moet in actie komen".

- **Europese vacatures, gerangschikt op je cv.** Plak een vacature en krijg een eerlijke score op 5: onder 4,0 raadt Agisse je af om te solliciteren.
- **Warme introducties** via echte raakvlakken: dezelfde universiteit, werkgever of studentenvereniging. Je stuurt je bericht altijd zelf; Agisse automatiseert LinkedIn nooit.
- **Voorbereiden en opvolgen:** de sollicitatierondes en online tests die een bedrijf gebruikt, oefenen met feedback, en één plek voor al je sollicitaties.

Agisse is gratis en open source ([AGPL-3.0](LICENSE)). Gebruik het op [agisse.xyz](https://agisse.xyz), of draai je eigen kopie: zie [Self-host](README.md#self-host) (Engels). De code is open; de vacaturefeed op agisse.xyz niet, dus een eigen kopie begint met een lege feed. Geen advertenties, geen verkoop van je gegevens, geen betaalde plaatsen.
