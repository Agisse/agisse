# Agisse

[English](README.md) · **Nederlands** · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Italiano](README.it.md) · [Polski](README.pl.md)

> Deze vertaling is nog niet nagelezen door een moedertaalspreker. Verbeteringen zijn welkom in een pull request.

Agisse is een copiloot voor je zoektocht naar werk, voor studenten en starters in Europa:

- **Een feed van Europese vacatures**, gerangschikt op je cv, met een eerlijke score: solliciteren of overslaan. Onder 4,0 raadt Agisse je af om te solliciteren.
- **Warme introducties** via echte raakvlakken: dezelfde universiteit, werkgever of studentenvereniging. Je stuurt je bericht altijd zelf; Agisse logt nooit in op je LinkedIn-account.
- **Voorbereiden en opvolgen**: de sollicitatierondes en online tests die een bedrijf gebruikt, oefenen met feedback, en een bord voor al je sollicitaties.

Gratis op [agisse.xyz](https://agisse.xyz): probeer het met gratis AI-modellen en koppel daarna je eigen OpenRouter-sleutel voor echt gebruik. Of draai je eigen kopie met `npx agisse`: zie de [self-host-gids](https://agisse.xyz/docs/self-host) (Engels). Geen advertenties, geen verkoop van gegevens, geen betaalde plaatsen in de feed.

Alle code is open (AGPL-3.0). De vacaturefeed op agisse.xyz niet: een eigen kopie begint leeg, en je vult ze met je eigen bron ([feed contract](https://agisse.xyz/docs/feed-contract), Engels).
